[ENUNCIADO]
O SNMP (Simple Network Management Protocol) oferece um padrão de arquitetura para monitoramento de ativos de rede. De acordo com este modelo de gerenciamento, o agente SNMP é o componente arquitetural que

[ALTERNATIVAS]
(A) especifica as estruturas comuns e esquemas de identificação dos elementos de rede.
(B) representa a base de dados de objetos que residem no dispositivo de rede.
(C) define o caminho que os pacotes de dados devem percorrer a partir do elemento de rede até as estações de gerência.
(D) atua como interface para o gerente humano num sistema de gerenciamento de rede.
(E) recebe mensagens para recuperar ou modificar variáveis no elemento de rede monitorado.
