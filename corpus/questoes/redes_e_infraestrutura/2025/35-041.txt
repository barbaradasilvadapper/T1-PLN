Os endereços IP virtuais oferecem flexibilidade, escalabilidade e alta disponibilidade em redes de computadores. Com relação aos endereços IP virtuais, analise os itens a seguir. I. Um endereço IP virtual pode ser compartilhado entre vários domínios ou vários servidores. II. O endereçamento IP virtual permite que um endereço IP seja usado quando vários sites são hospedados em um mesmo servidor. IPs virtuais também são amplamente usados para balancear o tráfego de entrada para vários servidores. III. Os pacotes de entrada são enviados para o IP virtual e encaminhados para o endereço IP real de um servidor.
