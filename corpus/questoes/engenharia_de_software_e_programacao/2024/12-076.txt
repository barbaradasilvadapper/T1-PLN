[ALTERNATIVAS]

(C) conforme o número de filhas (NOC, do inglês number of children) de uma classe aumenta, a quantidade de teste (necessário para exercitar cada classe filha) será reduzido.
(D) conforme o acoplamento entre objetos de uma dada classe (CBO, do inglês coupling between object classes) aumenta, a complexidade de testes por modificações dessa classe diminui.
(E) conforme a resposta para uma classe (RFC, do inglês response for a class) aumenta, a complexidade geral de projeto da classe aumenta.
