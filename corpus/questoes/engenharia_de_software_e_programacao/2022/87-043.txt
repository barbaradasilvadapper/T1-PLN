No âmbito da linguagem C#, analise o trecho de código a seguir. class Pessoa { private string nome; public string Nome { get { return nome; } set { nome = value; } } } A sintaxe C# permite que a sexta e a sétima linhas sejam resumidas pelo trecho:

[ALTERNATIVAS]
(A) { get; set; }
(B) { get(); set(value); }
(C) { get <- nome; set -> nome; }
(D) get { -> nome } set { nome <= args[] }
(E) get { return this.nome; } set { let this.nome = args[]; }
