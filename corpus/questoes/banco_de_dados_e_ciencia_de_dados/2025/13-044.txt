A álgebra relacional é uma linguagem de consulta formal, composta por diversas operações sobre conjuntos de dados, que fornece uma base teórica sólida para a otimização de consultas SQL em bancos de dados relacionais. A operação “seleção” da álgebra relacional é realizada pela cláusula SQL:

(B) SELECT
(C) EXISTS
(D) LIMIT
