Os sistemas de arquivos são fundamentais para a organização, armazenamento e recuperação de dados em sistemas computacionais. Um analista de segurança deve escolher um sistema de arquivos para um disco de armazenamento de dados onde será instalado o sistema operacional Linux Ubuntu. Dos sistemas de arquivos apresentados a seguir, assinale o mais apropriado para a instalação desse sistema operacional.
