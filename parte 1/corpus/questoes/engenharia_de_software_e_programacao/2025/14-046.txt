[ENUNCIADO]
Swagger é composto por um conjunto de ferramentas de código aberto criadas em torno da especificação OpenAPI que podem ajudar os desenvolvedores a construírem, documentarem e consumirem APIs REST. Com relação às ferramentas do Swagger, avalie as afirmativas a seguir e assinale (V) para a afirmativa e (F) para a falsa. ( ) Swagger Parser - É uma biblioteca autônoma para analisar definições OpenAPI no formato JSON ou YAML. ( ) Swagger APIDom - Fornece uma estrutura única e unificadora para descrever APIs em várias linguagens, por exemplo, RAML, API Blueprint, e formatos de serialização, como por exemplo XML, YAML ou JSON. ( ) Swagger SourceGen - Faz a geração automática de bibliotecas de cliente de APIs e stubs de servidor a partir de uma definição OpenAPI.

[ALTERNATIVAS]
(A) V – F – F.

(E) F – V – F.
